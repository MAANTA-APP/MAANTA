## Purpose

Clarify partner types, what MAANTA can offer now, and how a data pathway might exist later without overselling.

## Current reality

### Partner types

- **Partner:** BBS Mall management · **Now:** Pilot relationship framing; monthly health reports promised in product brief; MoU/term sheet **drafts unsigned** · **Not now:** Live automated mall-operator dashboard
- **Partner:** Merchants · **Now:** Onboarding, Elite trial, opening credit rules, verified redemptions · **Not now:** Fee waivers
- **Partner:** Marketing agency · **Now:** Brief + email sequences exist · **Not now:** Fully running campaign (gates open)
- **Partner:** Payment processors · **Now:** Stripe sandbox; IntaSend prepared · **Not now:** Assumed M-Pesa availability
- **Partner:** Data counterparties / “Oracle” · **Now:** None live · **Not now:** Any exclusive data feed narrative

### What partners can truthfully be told

- MAANTA verifies in-person redemptions and charges merchants a success fee.
- Node 0 focus is operational density at BBS.
- Mall value today is **footfall quality + verified offer performance summaries** (ops-produced), not a data platform.
- Shopper PII is not a mall reporting input (summary/node level only — see RLS posture).

## Future strategic path (data / Oracle-style)

Possible later direction (only after Node 0 works):

- Aggregated, consented, privacy-reviewed mall performance insights.
- APIs or dashboards for mall operators.
- Clear contractual basis + Kenya DPA compliance.

**Until built and governed, do not put Oracle language in decks, MoUs, or Notion product pages as if shipped.**

Frozen Scope historically lists Analytics/Oracle under “not building” for MVP — that remains correct for launch scope. This page exists so the *pathway* is documented without contradicting the freeze.
