# D208 / D211 B2b closure record — 2026-08-30

## Outcome

D208 and D211 are closed in code. The five executive fee surfaces now read the
structured B2a contract through `readLedgerFeeTotals`:

- `/admin`
- `/admin/reports`
- `/admin/pilot`
- `/founder`
- `/founder/yesterday`

An absent merchant scope calls `admin_fee_totals_global`. Any present scope,
including an empty array, calls `admin_fee_totals_for_merchants`; an empty node
therefore cannot fall through to marketplace-wide money.

## Presentation contract

Every surface exposes net, gross and reversals separately using the shared
labels in `components/admin/fee-figures.tsx`. The RPC result is accepted only
when `available = true` and all three amounts are finite. A read error, an
unavailable database result, or a malformed partial transport row maps all
three cards to an em dash. None can become a manufactured `KES 0`.

## What was removed

- `/admin` no longer pulls capped ledger rows into JavaScript or reduces them.
- `/founder` and `/admin/reports` no longer call the legacy
  `admin_success_fee_revenue` gross-only RPC.
- The application reader no longer rebuilds the SQL contract through four
  PostgREST reads. It delegates to the structured wrappers, eliminating the
  recorded TypeScript semantic gaps and the second implementation that caused
  them.
- Every `tsDivergence` and `notYetInTypeScript` fixture annotation was deleted.
