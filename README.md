# MAANTA

Kenya mall-deals marketplace, launching at BBS Mall, Nairobi. Shoppers
claim a 6-digit deal code in the app and redeem it in person; merchants
pay a KES 30 success fee per verified redemption from a preloaded wallet.

- **Application code:** [`maanta-app/`](maanta-app/) — Next.js 14 + Supabase
- **Launch handoff documentation:** [`docs/`](docs/README.md) — technical
  handoff, launch readiness tracker, waitlist spec, email/segmentation
  plans, agency brief, ops runbook
- **Legal drafts:** [`maanta-app/legal/`](maanta-app/legal/) — internal
  working copies, not published
